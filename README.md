# Kommo Client Manager

Integração entre Kommo CRM e WordPress.

## Objetivo

Automatizar a criação de usuários no WordPress quando um cliente entrar na etapa **Cliente com consulta** no Kommo.

## Funcionalidades da V1

- Webhook Kommo
- Criação automática de usuários
- Sincronização manual
- Área administrativa
- Logs
- Configurações
- Envio de e-mail
- Link para definição de senha
- Recuperação de senha
- Reenvio manual de acesso

---

## Estrutura

```
kommo-client-manager/
```

---

## Requisitos

- PHP 8.1+
- WordPress 6+
- Kommo CRM

---

## Instalação

1. Compacte o plugin em ZIP.
2. WordPress → Plugins → Adicionar novo.
3. Enviar Plugin.
4. Ativar.
