Guia Rápido de Configuração

Siga os 5 passos abaixo para conectar o Kommo ao WordPress em menos de 3 minutos

01 Kommo CRM

Criar Integração Privada

No painel do Kommo, acesse Configurações → Integrações → Criar Integração. Preencha o nome e selecione as permissões necessárias para Contatos e Leads.

02 Redirect URI

Definir Redirect URI

No campo Redirect URI da sua integração no Kommo, informe exatamente esta URL:

https://intern-yago.github.io/Kommo-Client-Manager-Plugin/
03 WordPress

Instalar o Plugin

Baixe o arquivo ZIP da release no GitHub, acesse WordPress → Plugins → Adicionar Novo → Enviar Plugin e clique em Ativar.

04 Autenticação

Informar Credenciais

No WordPress, vá em Kommo Manager → Configurações. Digite o Subdomínio, Client ID e Client Secret. Em seguida insira o Código de Autorização.

05 Automação

Configurar Webhook

Configure um Webhook na etapa de funil desejada (ex: Cliente com consulta) direcionado para o endpoint do plugin no seu WordPress para sincronização automática.

06 Pronto!

Pronto para Operar

Seus clientes Kommo agora serão sincronizados e terão contas de usuário criadas com envio automático de e-mail de definição de senha.

Perguntas Frequentes (FAQ)

Dúvidas comuns sobre a integração e redirecionamento OAuth

O que fazer se o Código de Autorização expirar? ↓

Os códigos de autorização do Kommo duram exatamente 20 minutos. Se expirar, basta abrir novamente a integração no Kommo, clicar para autorizar e gerar um novo código para colar no WordPress.

Como o plugin lida com a renovação do Token de Acesso? ↓

Uma vez realizada a primeira troca com o Código de Autorização, o plugin salva um Refresh Token e renova os acessos de forma automática antes que o Access Token de 24 horas expire.

Por que usar esta página no GitHub Pages como Redirect URI? ↓

Esta página serve como um hub central seguro e independente para capturar o código de autorização durante o processo de configuração inicial da integração privada do Kommo, facilitando a cópia sem depender de configurações complexas de SSL em ambientes de teste.
