Perguntas Frequentes (FAQ)

Respostas diretas sobre a integração e a Área VIP

Como funciona a segurança do código de 6 dígitos enviado por e-mail? ↓

Ao abrir o link VIP de primeiro acesso, o plugin envia um código de 6 dígitos para a caixa de e-mail do cliente registrado. O cliente precisa inserir esse código para confirmar sua identidade antes de cadastrar uma senha. Se o link for repassado por engano a terceiros, eles não terão acesso ao e-mail e não conseguirão entrar.

O que fazer se um cliente sincronizado não tiver e-mail? ↓

No painel em Kommo > Clientes, surgirá um botão azul "Cadastrar E-mail" na linha do cliente. Ao salvar o e-mail, o plugin vincula a conta no WordPress e libera o botão de "Copiar Link VIP" na hora.

O que acontece se o Código de Autorização OAuth expirar? ↓

Os códigos de autorização do Kommo duram 20 minutos. Se expirar antes da colagem no WordPress, basta abrir a integração no Kommo e gerar um novo código. Uma vez salva a conexão, o plugin gerencia a renovação dos tokens automaticamente.
